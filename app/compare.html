With and without Qloo.

Seven questions, each asked twice of the same model with the same prompt and settings. The first run has Zemi-Aku's Qloo tools. In six pairs the second run keeps only the map, the weather, Wikidata landmarks and Wikipedia history. In the last pair the second run also keeps Qloo's place catalog and loses only the taste tools, so the difference is Qloo's affinity signal, not the existence of a catalog. Places from Qloo's catalog are marked in the answers; the line under each pair says what Qloo changed, or that it added nothing.

Loading the saved runs…

The runs are saved in compare-qloo.json and made by scripts/compare-qloo.mjs against a local server. Since October 23 every live model answer in the app offers Ask again without Qloo, the same control run on demand. Catalog places are matched by name against what the Qloo run put on the map; a place the second run names from general knowledge is not verified.
